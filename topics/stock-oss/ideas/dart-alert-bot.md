# DART 공시 조건 알림 봇

- **JTBD**: 공시 변화를 놓치지 않으려는 상황에서 국내 종목을 지켜보는 개인 투자자가, 조건을 걸어 두면 알아서 오는 알림을 원한다 (J9). 겸해서 "국내 데이터가 수시로 끊긴다"(J2)·"코드를 못 쓴다"(J4)·"공시가 그대로는 못 쓰는 형태다"(J10)에 답한다.
- **수요 근거**: signal #59·61·63·111·112·234·235·240·303·304·309·312·314·318·320~322·324·326·327·329·363·367·368 **24건 (레포 7곳, 반응 합계 53)**
  - 대표 인용: "사업 보고서 정정공시가 발생하는 경우가 종종 있습니다. … 정확한 데이터를 위해 필요하다 생각합니다"(#303 w3) · "It would be good to have a way to manage alerts programatically."(#111 w6) · "It would be awesome if we could set the alerts with respect to a dynamically evaluated value like SMA"(#234 w3) · "what would be more useful (for me) is taking these feeds and using AI to interpret them and have alerts / notifications tailored to me on my phone"(#329 w5) · "실행할때마다 불러오려니 시간도 오래걸리고, api count도 쓸데없이 계속 올라가게 됩니다"(#304 w2)
- **기존 대안·경쟁**: OpenDartReader·korean-dart-mcp 는 **조회용(pull)이라 푸시가 없고**, 메인테이너가 가공 기능 추가는 검토하지 않는다고 답했다(#306·#312). 웹 확인: **DIY 오픈소스 봇이 이미 여럿 있다** — `dart-telegram-bot`·`my-dart-monitor`·`kr-stock-watch` 등이 GitHub Actions 로 서버 없이 무료 운영된다. 즉 **개발자는 이미 해결했고, 비어 있는 것은 비개발자용 호스팅판**이다(그래서 차별성 3). 증권사 앱 공시 알림의 조건 지정 범위는 확인하지 못했다.
- **규제 위치**: **무료 정보·도구**. 사용자가 티커·공시유형만 고르는 필터링은 개별성에 해당하지 않을 가능성이 크다(대법원 2018도4413 — 개별성은 투자목적·재산상황·투자경험 반영 여부로 본다). 해석 없는 사실 요약으로 한정한다.
- **1인 실현성·재사용 자산**: 실현성 **5**, 재사용 **5**. GuruNote 의 수집→상태 DB→발송 구조는 **소스 중립**이라 SEC 자리에 DART OpenAPI 를 꽂으면 된다. 운영 중인 텔레그램 봇·사용자별 구독 DB 를 그대로 쓴다. 속보성은 OpenDartReader 의 접수 시각 조회로 확보한다.
- **사전부검 — 6개월 뒤 실패했다면**
  1. DIY 봇으로 충분한 층이 두꺼웠다. 직접 돌릴 사람은 이미 돌리고 있어 호스팅에 값을 느끼는 층이 얇았다.
  2. 증권사 앱 공시 알림이 무료로 같은 걸 덮었다(현재 미확인 — 확인되면 차별성이 1로 떨어진다).
  3. 1인 무승인 발송이라 오발송·중복 발송 한 번이 신뢰를 끝냈다.
- **검증 가설**
  - 누가 무엇을 할 것: **먼저 확인부터 한다.** 증권사 앱(키움·토스·미래에셋)의 공시 알림이 종목·공시유형 조건을 지원하는지 직접 확인하고, 지원하면 이 아이디어를 접는다. 통과하면 지원자 5~10명에게 관심 종목을 받아 **2주간 손으로 DM** 한다(GuruNote 컨시어지 방식).
  - 성공 기준: ① 증권사 앱이 공시유형별 조건 알림을 제공하지 않는다 ② 2주 동안 참여자 절반 이상이 알림에 반응한다 ③ 끝났을 때 "계속 받고 싶다"가 절반 이상이다.
  - 접을 기준: 증권사 앱이 이미 같은 걸 무료 제공하거나, 반응이 30% 미만이면 접는다.
