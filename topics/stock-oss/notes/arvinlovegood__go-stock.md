## 무엇·어떻게

Wails(Go 백엔드 + Vue/NaiveUI 프런트) 데스크톱 앱으로 만든 A주 중심 AI 주식 분석 도구다. 시세·뉴스·수급 데이터를 긁어 와 LLM 에게 넘겨 종목 분석·시장 요약·추천 종목·복기 리포트를 만든다. clone HEAD `c26304fafab0796765147c7db5049a9c3686319b`, 라이선스 GPLv3, 2024-12 생성, 2026-09-26 까지 거의 매일 커밋(README 변경 기록 기준). 개발자 1인(ArvinLovegood) 중심이고, README 에 "개발 환경은 주로 Windows10+, 다른 플랫폼은 미검증이거나 기능 제한"이라고 적혀 있다.

- 구조: 루트 `app.go`(약 19만 바이트 단일 파일)·`main.go`, `backend/data`(데이터 수집 API 100여 파일), `backend/agent`(에이전트·백테스트·지식베이스·장기 기억·자기 진화 SOUL.md·飞书 봇·cron), `backend/agent/tools`(34개 파일, README 기준 "150+ AI 데이터 도구"), `ai-assistant-web`(같은 로컬 DB 를 쓰는 별도 웹 서버), `frontend`(Vue). 저장소는 로컬 SQLite, 벡터 검색은 chromem-go. 에이전트는 cloudwego eino ADK 로 React/PlanExecute/DeepAgents 세 모드를 둔다. DeepAgents 모드는 파일시스템·StreamingShell 로 "Agent 가 소스를 읽고 스크립트를 실행"할 수 있다.
- 데이터 소스: 전부 공식 API 가 아닌 웹 엔드포인트 스크래핑이다. 코드 속 도메인 빈도 상위 — 东方财富(eastmoney, 데이터센터·K선·F10·ai-saas), 财联社(cls.cn, 전보·캘린더), 新浪财经, 同花顺(10jqka·问财 iwencai), 百度股市通, 雪球, 腾讯(gtimg), TradingView 뉴스, Reuters, 정부 부처 정책 사이트(gov.cn·csrc·nfra 등), 통달신(通达信) MAC 프로토콜. 일부는 Edge/Chrome 을 chromedp 로 띄워 크롤링한다. Tushare 토큰은 선택.
- 시장: A주·홍콩·미국·장내 ETF·펀드. 한국은 2026-08 에 "해외 지수와 한국 주식 시세 인터페이스(Naver fchart 보충)"를 넣었다(`backend/data/korea_stock_api.go`). 东方财富 코드 `177.` 접두 종목과 KOSPI 지수의 일봉·분봉을 Naver fchart XML 로 받는 정도이고, 중국어 표시명 매핑은 KOSPI·삼성전자·SK하이닉스 3개뿐이다. 대만은 이슈 #7 에서 "지원 안 함" 답변.

- 수익화: README "开源支持计划" — VIP0 무료(전체 기능·GitHub 에서 자동 업데이트), VIP2 월 28.8 RMB / 연 240 RMB(시작 때 최근 24시간 시장 뉴스·외신 동기화, go-stock AI 助手, 후방 매매 신호 모니터링 등), VIP1 판매 중지. 1:1 기술지원 회당 100 RMB, 장기 지원 5000 RMB. 硅基流动·火山方舟·Tushare 추천 링크, "README 광고 게재 접수" 문구도 있다. VIP 판정은 후원 코드를 빌드 때 ldflags 로 넣은 키로 로컬 AES-ECB 복호화해 기간을 확인하는 방식(`backend/data/sponsor_vip.go`), VIP 뉴스는 작성자 서버(`go-stock.sparkmemory.top:16666`)에서 받는다. 프롬프트·스킬 광장도 작성자 서버 계정 기반이고 기기 ID 로 최대 5대 바인딩을 확인한다.

## 성과 주장의 신뢰도

1. 주장 목록 — README·`docs/*.md` 20여 개·README 스크린샷(`build/screenshot/img.png`·`img16.png` 등)을 `胜率|收益率|准确率|夏普|跑赢|超额|年化` 로 전수 grep·열람했다. 레포 자신의 수익률·적중률 수치 주장은 없다. 나오는 것은 모두 사용자가 자기 데이터로 돌리는 **평가 기능의 지표 이름**이다.
   - 프롬프트 템플릿 백테스트(beta, 2026.09): "历史行情重放+防未来数据机制，胜率/回撤/夏普/Jaccard稳定性等指标对比多个提示词模板"(README 기능 표). 문서(`docs/2026.09新功能介绍与使用说明.md` §3.2)는 "杜绝未来函数，保证回测可信"라고 백테스트 신뢰성을 단언한다 — 수치 주장은 아니지만 과장된 방법론 주장이다(아래 3 참고).
   - 추천 백테스트 통계: "AI推荐个股按持有期计算实际收益并与沪深300对比，按模型/提示词/评级多维统计"(README).
   - 신호 수익 통계(VIP2): 9路 공진 매수·매도 신호를 "买点开仓、卖点平仓"으로 짝지어 누적 수익·승률 집계.
   - `docs/交易日志与每日操作计划AI实战指南.md` 의 "『贪婪』心态下的加仓胜率仅 20%" 같은 수치는 AI 복기 출력 예시이지 성과 주장이 아니다.
   - 참고: 제3자 블로그(CSDN 등)의 "2026년 AI 종목 선정 도구 정확도 55~70%" 는 레포 주장이 아니다.
2. 면책 문구 — README "本项目仅供娱乐，不喜勿喷，AI分析股票结果仅供学习研究，投资有风险，请谨慎使用。", 앱 제목줄·워터마크 "数据来源于网络,仅供参考;投资有风险,入市需谨慎".
3. 검증 수단(평가 기능 자체의 설계)
   - 추천 백테스트(`backend/agent/recommend_backtest.go`): AI 가 추천할 때 기록을 자동 저장하고, 이후 3·5·10·20·30 거래일 뒤 종가로 수익을 계산해 沪深300 과 비교한다. 추천 시점 이후 가격으로만 평가하므로 **구조적으로 포워드 기록**이다. 단 결과는 각 사용자 로컬 DB 에만 쌓이고 레포가 공개한 누적 성적은 없다.
   - 프롬프트 템플릿 백테스트(`prompt_backtest_engine.go`): 거래일마다 그날까지의 지수 K선·시장 통계·龙虎榜·섹터 자금흐름만 프롬프트에 넣어 데이터 look-ahead 는 막는다. 그러나 달력이 沪深300 일봉 최근 300개(약 1년 3개월)라 대상 구간이 대부분 LLM 학습 컷오프 이전일 수 있고, **LLM 기억 누출 대책이 없다**. 코드 주석도 "실시간 시간 컨텍스트와 '오늘은 D' 충돌을 강한 앵커 문구로 완화"한다고만 적는다. 표본 ≤60일, 종목 수는 날마다 모델이 고른 N개.
   - 공통: 수수료·인지세·슬리피지 미반영(종가 대 종가 단순 수익률), 상장폐지·생존 편향 대책 없음, 신호 수익은 "각 거래 수익률의 단순 합"을 누적 수익으로 쓴다. 2026-09-23 변경 기록에서 "이전에는 화살표 좌표(매수=저가, 매도=고가)를 체결가로 써서 수익을 계통적으로 과대 추정"하던 것을 종가로 고쳤다고 스스로 밝혔다.
4. 판정 — 레포는 수익률·적중률을 주장하지 않는다. 사용자가 자기 추천을 포워드로 추적하는 평가 도구를 제공한다(앵커 5). 다만 "保证回测可信"은 기억 누출을 무시한 과장이므로, 프롬프트 백테스트 결과를 성과 근거로 쓰면 3 수준이다.

심층 T 5 (판정 T 5) — 성과 수치 주장이 없고, 추천 백테스트는 추천 시점 이후 가격으로 매기는 포워드 기록이다(단 프롬프트 백테스트는 기억 누출 대책 없음).

## 파생·상용화

- 본인 상용: VIP 후원 구독(월 28.8 / 연 240 RMB)이 핵심이다. 기능 대부분은 VIP0 에서 무료이고, 유료는 작성자 서버의 24시간 뉴스 동기화·AI 助手·후방 신호 모니터링 같은 "서버 데이터 + 상시 알림"이다. 여기에 유료 기술지원, LLM API 추천 링크(硅基流动·火山方舟), Tushare 추천 링크, README 광고 게재, 스폰서(Anspire·UCloud, 지금은 주석 처리)를 겹친다. 앱 제목줄에 "未经授权,禁止商业目的"(무단 상업 이용 금지)이라고 띄우는데 라이선스는 GPLv3 라 법적 효력과 맞지 않는다.
- 포크: 1,352개지만 ★순 상위 10개가 모두 ★1 이고 설명까지 원본과 같은 개인 미러다(`Trade-zhanchang`·`molua1`·`flinglee` 등). pull[bot] 로 원본을 따라가는 미러(`LeeeeeeM/go-stock`)도 있다. 의미 있는 파생 포크는 없다. Gitee 미러를 작성자가 직접 운영한다.
- 제3자 유료 래퍼: 웹 검색 2회로 찾지 못했다. 중국 블로그(知乎·CSDN·IT之家)에서 "무료인데 유료 제품 대부분보다 낫다"는 소개 글로 유입된다. 비교 대상으로는 同花顺 问财·新浪财经 AI 같은 증권사·포털 내장 AI 가 거론된다.

## 내 투자에 쓰려면

- 실행: 릴리스 바이너리(Windows exe·mac universal)가 기본 경로이지만 서명되지 않았고 자동 업데이트가 GitHub 에서 받아 교체하는 구조다. 쓰려면 소스를 직접 읽고 Wails CLI 로 빌드하는 편이 안전하다(이번 조사에서는 빌드·실행하지 않았다). 설정에서 OpenAI 호환 API 키(DeepSeek 등)나 로컬 Ollama 를 넣고 관심 종목을 추가한다.
- 한국 투자 관점: 한국 종목은 Naver fchart 일봉·분봉 보충 정도라 재무·공시·수급·뉴스는 없다. 150개 도구 대부분이 A주 전용(龙虎榜·游资·涨停梯队·融资融券·부처 정책)이라 한국 주식에는 거의 쓸모가 없다. 미국 주식은 시세·K선 정도.
- 주의: (1) 데이터가 전부 중국 사이트 스크래핑이라 수시로 깨진다. (2) DeepAgents 모드는 에이전트가 셸 명령을 실행할 수 있고, 스킬 광장에서 남이 올린 스킬 ZIP(스크립트 포함)을 한 번에 가져온다 — 공급망 위험이 있으니 쓰지 않거나 격리해야 한다. (3) 광장·VIP 기능은 작성자 서버 계정·기기 ID 바인딩을 쓴다. (4) 추천 백테스트 수익은 수수료·슬리피지를 빼지 않은 종가 기준이다.
- 쓸 만한 것: "AI 추천을 자동 저장 → N일 뒤 벤치마크 대비 채점 → 모델·프롬프트별 승률"이라는 포워드 채점 루프 설계는 한국 종목용 내 도구에 그대로 옮길 만하다.

## 인디 관점 메모

- 공백: (1) **공개 포워드 성적표** — #140 이 보여 주듯 사용자는 "진짜 돈이 되나"를 묻지만, 추천 백테스트는 각자 로컬에 갇혀 있다. 모델·프롬프트별 AI 추천을 공개 기록(타임스탬프 고정)으로 쌓아 보여 주는 리더보드는 비어 있다. (2) **상시 가동·호스팅** — Docker·웹 UI·장 마감 후 자동 처리 요청이 반복되는데 구조는 PC 데스크톱 앱이다. 작성자도 유료 등급을 "서버 뉴스 + 백그라운드 알림"으로 짰다 — 돈을 내는 지점이 상시 가동임을 보여 준다. (3) **한국판** — A주 전용 도구(龙虎榜·游资席位·涨停梯队) 자리에 한국형(외국인·기관 수급, 공매도, 상한가·테마, DART 공시)을 넣은 같은 형태의 제품이 없다.
- 차용: 추천 자동 저장 + 다중 보유 기간(3/5/10/20/30일) 벤치마크 대비 채점, 프롬프트 템플릿 A/B 백테스트와 Jaccard 출력 안정성 지표, "매일 복기 ↔ 장전 전략" 폐쇄 루프(전날 장전 예측을 다음 날 복기가 인용), 飞书·钉钉 봇 진행 카드, 저가 후원 구독(월 3~4천 원 수준) + 프롬프트·스킬 광장으로 커뮤니티를 수익화하는 모델.
- 경계: 프롬프트 백테스트 방식(최근 1년 남짓 과거 재생)은 LLM 기억 누출 때문에 그대로 가져오면 안 된다. 포워드 기록만 성과 근거로 쓴다.
