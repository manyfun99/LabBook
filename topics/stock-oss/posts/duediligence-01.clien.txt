주식 오픈소스 429개를 같은 기준으로 판정해 봤습니다 — AI 성과 주장을 거르는 5가지 질문

GitHub 에서 주식·투자 오픈소스 3,771개를 모았습니다. 범위 기준(스타·최근 성장·한국 관련)을 통과한 772개 중 429개를 같은 루브릭으로 판정했고, 그중 19개는 README·이슈·코드를 깊게 읽었습니다.

이 글은 "AI 가 매매를 판단해 준다"는 도구를 깔까 말까 고민하는 분을 위한 것입니다. 결론부터 말하면, 도구를 고르기 전에 성과 주장을 거르는 질문 5개를 먼저 던져 보시길 권합니다.

기준일: 2026-10-06 (스타 수와 README 문구를 이날 다시 확인했습니다)

■ 1. 성과 주장을 거르는 5가지 질문

README 나 홍보 이미지에 수익률이 보이면 아래 다섯 가지를 확인합니다.

- ① 단순합인가
    · 무엇을 보나: 거래마다 낸 수익률을 그냥 더한 값인가, 자금 배분을 반영한 계좌 수익률인가
- ② 비용을 뺐나
    · 무엇을 보나: 수수료·거래세·슬리피지를 반영했나
- ③ 벤치마크가 있나
    · 무엇을 보나: 같은 기간 지수(KOSPI·S&P500)나 단순 보유와 비교했나
- ④ 컷오프 이후인가
    · 무엇을 보나: 사용한 LLM 의 학습 컷오프 이후 구간인가, 실시간 기록인가
- ⑤ 표본이 몇 건인가
    · 무엇을 보나: 기간·종목·거래 수는 얼마이고, 한 번의 시장 국면에만 걸쳐 있지 않은가

④가 AI 도구에서 특히 중요합니다. LLM 은 학습 컷오프 이전의 가격 흐름을 기억합니다. 그 구간의 백테스트는 예측이 아니라 회상일 수 있습니다(arXiv 2504.14765 https://arxiv.org/abs/2504.14765 ). 기간과 종목을 넓히면 LLM 전략의 우위가 크게 줄어든다는 결과도 있습니다(FINSABER, arXiv 2505.07078 https://arxiv.org/abs/2505.07078 ). 오염되지 않은 구간에서 단순한 기준선을 이기는 경우도 드뭅니다(StockBench, arXiv 2510.02209 https://arxiv.org/abs/2510.02209 ).

■ 2. 실제로 적용해 보면 — 사례 둘

▶ TradingAgents — 논문의 샤프 지수 8.21

★11만으로 이 분야에서 가장 유명한 프로젝트입니다. 논문(arXiv 2412.20138 https://arxiv.org/abs/2412.20138 )은 AAPL 에서 샤프 지수 8.21, 연 환산 수익률 30.5% 를 보고했습니다.

- ① 단순합 아님 ○ — 종목별 누적 수익률입니다.
- ② 비용 ✗ — 논문에 수수료·슬리피지 언급이 없습니다.
- ③ 벤치마크 ○ — 단순 보유를 포함한 기준선 5개와 비교했습니다.
- ④ 컷오프 △ — 논문은 모델 컷오프를 다루지 않습니다. 코드에서 미래 데이터가 섞이는 문제가 여러 차례 보고됐고 2026년에야 차례로 고쳐졌습니다. 모델이 과거를 기억하는 문제(#805 https://github.com/TauricResearch/TradingAgents/issues/805 )에 대해 메인테이너는 "코드 수정으로 완전히 없앨 수 없는 한계"라고 답했습니다.
- ⑤ 표본 ✗ — 3개월·3종목입니다. 논문 스스로 "최고 샤프 지수가 예상 범위를 넘는다"고 적었습니다.

같은 AAPL 구간을 재현한 사용자는 −25.4%를 얻었습니다(단순 보유 −7.6%, #168 https://github.com/TauricResearch/TradingAgents/issues/168 ). 그렇다고 도구 자체가 쓸모없지는 않습니다. 2026년 들어 시점별 데이터 처리를 크게 정비했고, 종목 하나를 여러 관점에서 정리하는 리서치 초안 생성기로는 쓸 만합니다. 다만 등급 한 번을 매매 신호로 쓰기는 어렵습니다. 같은 입력에서도 실행마다 결과가 달라집니다.

▶ PRISM-INSIGHT — +244% 에서 "KOSPI 에 졌다"로

한국 1인 개발자가 2025년 3월부터 운영해 온 무료 AI 급등주 분석·가상매매 시스템입니다(★769). 텔레그램 채널과 대시보드로 거래 단위 기록을 공개합니다.

9월 말까지 README 의 헤드라인은 누적 수익률 +244.63%(86건)였습니다. 5가지 질문으로 보면 이렇습니다.

- ① 단순합 ✗ — 거래 86건의 수익률을 그냥 더한 값이었습니다. 10슬롯 계좌로 환산하면 약 +25% 입니다.
- ② 비용 ✗ — 시뮬레이터 수익률 공식에 수수료·거래세가 없었습니다.
- ③ 벤치마크 ✗ — 같은 기간 KOSPI 는 약 +62% 였지만 README 에는 비교가 없었습니다.
- ④ 컷오프 ○ — 백테스트가 아니라 매일 쌓은 포워드 기록입니다. 이 점은 드물고 좋습니다.
- ⑤ 표본 △ — 6개월·86건이고, 운영자 자신의 DB 기록입니다.

그런데 10월 4일 README 가 바뀌었습니다(a4d235f https://github.com/dragon1086/prism-insight/commit/a4d235f ). 지금은 두 측정을 나란히 보여 줍니다. 한국 시즌 2(2025-09-30~2026-10-02, 청산 211건)의 거래별 단순합은 +355.3% 이고, 10슬롯 계좌 수익률은 +35.2% 입니다. 같은 기간 KOSPI 는 +103.5% 였습니다. 한국어 README 는 "이 기간 계좌 수익률은 코스피에 뒤졌습니다. 이 점을 숨기지 않고 말씀드립니다."라고 적었습니다.

①·③이 풀렸습니다. ⑤는 1년·211건으로 늘었지만 README 스스로 "대형 반도체주가 이끈 상승장"이라고 한 한 번의 국면이고, 여전히 운영자 자신의 DB 기록이라 △입니다. ②는 아직 README 에 비용 반영 여부가 없습니다. 성과 주장이 고쳐지는 과정을 보여 주는 좋은 사례입니다. 서버가 접수 시각을 먼저 찍고 소급 입력을 막는 봉인 리더보드(Stance)도 만들고 있습니다.

■ 3. 많이 깔리는 AI 도구 5개 채점표

심층분석 노트가 있는 AI 도구 중 스타 상위 4개와 한국 1개를 골랐습니다(스타 3위 daily_stock_analysis 는 심층분석을 하지 않아 뺐습니다). 감사 칸 기호는 ○ 통과 · ✗ 실패 · △ 부분 · – 수치 주장 없음입니다. 수치 주장이 없는 도구는 대신 도구가 갖춘 검증 장치를 적었습니다.

- TradingAgents https://github.com/TauricResearch/TradingAgents (11만)
    · 한국 지원: .KS 시세만. 재무·뉴스는 yfinance 이고 DART 없음
    · 실제 비용: LLM 키. 결정 1회에 LLM 호출 16~22회 (소형 모델 실측 약 $0.12, 2025-07)
    · 성과 주장 → 감사 ①②③④⑤ (주장이 없으면 검증 장치): 논문 SR 8.21 → ○✗○△✗ (재현 −25.4%)
    · 쓸 곳: 종목 하나의 다관점 리서치 초안
- MiroFish https://github.com/666ghj/MiroFish (7.7만)
    · 한국 지원: 한국어 출력 설정 없음. 가격·재무 데이터를 넣는 경로 없음
    · 실제 비용: LLM + Zep. Zep 무료 한도는 실험 한두 번에 끝난다는 보고
    · 성과 주장 → 감사 ①②③④⑤ (주장이 없으면 검증 장치): 정성 주장("미래를 정밀하게 추론")뿐 → –––––. 검증 기록이 없고, 메인테이너 측 자동 답변도 "통계적으로 보정된 예측이 아니다"라고 했습니다(#237 https://github.com/666ghj/MiroFish/issues/237 )
    · 쓸 곳: 뉴스가 나온 뒤 "투자자 반응 시나리오" 체크리스트
- ai-hedge-fund https://github.com/virattt/ai-hedge-fund (6.4만)
    · 한국 지원: 불가 (미국 SEC 기반 데이터 하나뿐)
    · 실제 비용: 데이터 구독이 주 비용 (월 $199 가 비싸다는 이슈 #365 https://github.com/virattt/ai-hedge-fund/issues/365 )
    · 성과 주장 → 감사 ①②③④⑤ (주장이 없으면 검증 장치): 수치 주장 없음 → –––––. 검증 장치: 백테스트에서 종목명·날짜를 가리는 blind 모드, 벤치마크 곡선, 10-01 에 추가된 해시체인 원장 페이퍼 트레이딩. 비용 반영은 README 에 없음
    · 쓸 곳: 미국 종목 학습용 체크리스트
- Vibe-Trading https://github.com/HKUDS/Vibe-Trading (3.5만)
    · 한국 지원: .KS·.KQ 시세(pykrx·Yahoo), 한국 세금·호가 단위 엔진, KIS 모의투자
    · 실제 비용: LLM 키. 공개된 실측 없음
    · 성과 주장 → 감사 ①②③④⑤ (주장이 없으면 검증 장치): 수익 주장 없음("this project doesn't make a profit claim") → –––––. 검증 장치: 시장별 비용 반영 엔진, 10-01 에 추가된 모델 학습 컷오프 노출 경고(#1618 https://github.com/HKUDS/Vibe-Trading/pull/1618 )
    · 쓸 곳: 자연어로 규칙 전략 백테스트, 내 거래 습관 진단
- PRISM-INSIGHT https://github.com/dragon1086/prism-insight (769)
    · 한국 지원: 한국 중심 (KIS 앱키 필요)
    · 실제 비용: 운영비 월 약 $310 (API 약 $280 + 서버, 2026-01 대시보드). 직접 돌리기보다 무료 채널을 보는 편이 쌈
    · 성과 주장 → 감사 ①②③④⑤ (주장이 없으면 검증 장치): 10슬롯 +35.2% vs KOSPI +103.5% → ○✗○○△ (9월 말 README 기준이면 ✗✗✗○△)
    · 쓸 곳: DART 원문을 인용하는 종목 리포트, 1차 스크리닝

표에서 보이는 것은 두 가지입니다.

- 수익률을 내세운 곳일수록 감사에서 많이 걸립니다. 반대로 수익을 주장하지 않는 도구(ai-hedge-fund·Vibe-Trading)는 기억 누출·비용 같은 검증 장치를 먼저 만들고 있습니다.
- 한국 지원은 대부분 없거나 시세 수준입니다. 공시(DART) 원문을 쓰는 AI 도구는 이 다섯 중 PRISM-INSIGHT 하나입니다.

■ 4. 그래서 뭘 깔까

- 데이터부터 깝니다. 한국이면 시세·상장목록은 FinanceDataReader https://github.com/financedata/FinanceDataReader , 공시·재무는 OpenDartReader https://github.com/FinanceData/OpenDartReader 가 기본입니다. Claude 같은 에이전트에서 공시를 묻고 싶다면 korean-dart-mcp https://github.com/chrisryugj/korean-dart-mcp 를 쓸 수 있습니다. 버전을 고정해 수동으로 등록하세요.
- AI 도구는 리서치 초안으로만 씁니다. 숫자는 원자료와 대조합니다. 같은 질문을 여러 번 돌려 결론이 흔들리면 쓰지 않습니다.
- 검증은 컷오프 이후 구간이나 페이퍼 트레이딩으로만 합니다. 과거 백테스트 수익률은 위 5가지 질문을 통과하기 전까지 믿지 않습니다.

■ 5. 방법과 한계

- 판정과 심층분석은 Claude(LLM)가 했습니다. 개인 활용도·인디 기회·차용 가치·주장 신뢰도의 4축 루브릭으로 채점했습니다. 사람이 하나하나 검증한 결과가 아닙니다.
- 이번 조사에서는 도구를 설치하거나 실행하지 않았습니다. 비용과 한국 지원은 README·이슈·코드를 읽고 정리했습니다.
- 스타 3위인 daily_stock_analysis(6.6만)는 심층분석을 하지 않아 표에서 뺐습니다.
- 수치는 기준일의 README·이슈를 따릅니다. 프로젝트가 빠르게 바뀌므로 링크로 원문을 확인해 주세요. 틀린 곳을 알려 주시면 고치겠습니다.
- 방법과 원자료(판정 기준·레포별 노트)는 GitHub 에 공개해 두었습니다: manyfun99/LabBook https://github.com/manyfun99/LabBook/tree/main/topics/stock-oss

이 글은 오픈소스 도구에 대한 평가이고, 특정 종목이나 매매에 대한 의견이 아닙니다.
